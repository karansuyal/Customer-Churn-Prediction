## Project Description
Customer churn (customers leaving a company) directly hurts a telecom company's revenue. This project analyses the **IBM Telco Customer Churn** dataset to understand *why* customers leave, and builds a machine-learning model that predicts which customers are likely to churn so the business can take action early.

The project covers the complete data-analytics workflow: data cleaning, exploratory data analysis (EDA), feature engineering, model building and comparison, hyper-parameter tuning, threshold tuning, explainability (feature importance) and customer risk segmentation.

## Dataset
- **Name:** IBM Telco Customer Churn
- **Size:** 7,043 customers, 21 columns (demographics, services, account and billing info, churn label)
- **Link:** https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv
- **Raw CSV used by the notebook:** https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
- A local copy (`Telco-Customer-Churn.csv`) is included in this repository as a fallback.

## Technologies Used
- Python 3.10+
- Pandas, NumPy - data handling
- Matplotlib, Seaborn - visualisation
- Scikit-learn - ML models, pipelines, GridSearchCV, evaluation metrics
- Joblib - model saving
- Jupyter Notebook

## Machine-Learning Models
Logistic Regression, Random Forest, Gradient Boosting and a tuned Gradient Boosting model, compared using 5-fold cross-validation and test-set metrics.

## Key Results
| Item | Value |
|---|---|
| Overall churn rate | 26.5% |
| Final model | Tuned Gradient Boosting |
| ROC-AUC | 0.846 |
| Recall (tuned threshold 0.35) | 71.1% |
| F1-score | 0.633 |

**Main churn drivers:** tenure, internet service type, contract type, monthly charges, tech support.
Month-to-month contracts churn at 42.7% vs 2.8% for two-year contracts; customers in their first 12 months churn at 47.4%.
